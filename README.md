# Slides — JuMP-dev 2026 (and SIAM Optimization)

Presentation slides for two 2026 talks, both centered on **ExaModels.jl**.

## Talks

1. **JuMP-dev 2026** (current focus) — emphasis on the **software** side of ExaModels:
   the implementation, the API, GPU acceleration, how it plugs into the Julia
   optimization ecosystem (MadNLP, etc.).
2. **SIAM Optimization** (later) — emphasis on the **design principles and ideas**
   behind ExaModels: SIMD abstraction of repeated algebraic structure, automatic
   differentiation strategy, why the design enables GPU performance.
